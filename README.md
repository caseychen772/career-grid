# 生涯方格｜自我探索

繁體中文生涯探索網頁，包含自我訪談、生涯方格與「我的想法」選單。

## 使用流程

1. 依個性、興趣、價值、能力與感受，完成 12 題自我訪談。
2. 填入 3 種喜歡、3 種不喜歡、4 種了解的工作，並排序喜好。
3. 從 60 項工作特性中選出 10 項，選擇偏好的方向。
4. 回到生涯方格，排列特性的重要性，並對 10 種工作與理想工作逐項評分。

支援分段填寫、排序自動交換、漏填檢查、完整方格檢視與列印。

前 27 項保留原版文字與順序，第 28–60 項為新增的延伸探索選項，涵蓋遠端工作、工時、合作方式、工作內容與生活安排；不屬於原始教材。既有答案保持相容。

## 在自己的電腦執行

這是純 HTML、CSS 與 JavaScript 網頁，不需要安裝依賴或建置。

```sh
python3 -m http.server 8000
```

開啟 http://localhost:8000 。

## 檔案

- `index.html`：頁面結構與原版操作說明。
- `style.css`：電腦、手機與列印版面。
- `app.js`：題目、選單、填寫流程與評分邏輯。

## 資料保存

答案僅保存在使用者目前瀏覽器的 localStorage，使用 `career-grid-v1` 鍵值；不會上傳至伺服器，也不會跨裝置同步。更換網站網址時，原網址的暫存答案不會自動轉移。清除瀏覽器資料可能刪除答案，可用列印另存 PDF 保留。

儲存庫只包含網站程式碼，不包含任何填答資料。
